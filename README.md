# Gail's Reading Garden (web copy)

The stand-alone web copy of the app, for devices that can't open claude.ai (such as an iPad on iPadOS 15).
Progress is saved on the device. Use Grown-ups, then Tools, then "Save a backup" now and then.

This folder is generated. The source lives in the private gails-reading-garden repository:
`python3 build.py reading-garden.html full-build.html` then `python3 tools/build_site.py full-build.html ../gails-reading-garden-site/index.html`.
